# Session 2 Research: Cognitive Frameworks

**Research date:** 2026-08-26
**Course:** Gemini Pro
**Session:** Day 1, Session 2 — Cognitive Frameworks

## Scope and current guidance

This session uses role assignments, competing viewpoints, explicit output formats, and verification steps to make workplace decisions easier to inspect. The board-of-three-experts exercise is a practical prompting pattern, not evidence that Gemini contains three independent experts. It asks one model to simulate distinct lenses, so the output can still share the model's blind spots and should not be treated as an independent vote.

Google's Gemini guidance describes balanced presentation of multiple points of view for potentially divisive topics unless the user requests a specific perspective. Google's prompt-design guidance also recommends precise instructions, grounded context, and explicit verification. In the classroom, teach learners to define the decision, constraints, criteria, and evidence before assigning roles.

## Recommended prompt pattern

Use a five-part structure: decision and context, role lenses, required debate or analysis, output schema, and verification rule. A suitable request is:

```text
We are deciding whether to adopt [tool/process] for [team and goal]. Consider these constraints: [budget, timeline, security, migration]. Have a risk manager, an optimistic innovator, and a pragmatic project manager examine the decision. For each role, state assumptions, strongest argument, risks, and evidence needed. End with a consensus table of risks, rewards, recommendation, confidence, and unresolved questions. Mark claims that require external verification.
```

Requesting a transcript followed by a consensus table improves traceability, but consensus is a synthesis generated by the same model. Learners should challenge generic arguments, expose missing criteria, and verify factual claims with authoritative sources. Gemini's Modify feature can iterate on a response, while sources or double-check features may be available depending on the product surface and account.

## Industry relevance

Docusign describes using “gold standard” Gemini responses to refine prompting and make workflows more consistent. Equifax reports a secure adoption approach in which Gemini was evaluated across business units and 97% of trial participants wanted to retain their licenses. These customer-reported stories support a lesson about adoption, repeatable prompt quality, and security review, not a guarantee that simulated personas improve every decision.

A good workplace application is software-tool selection: the risk lens asks about security, procurement, and lock-in; the optimistic lens identifies capability and adoption opportunities; the project lens tests rollout effort, ownership, and measurable success. The final recommendation should name what evidence is still missing.

## Risks and teaching guardrails

Multiple personas can create false balance, amplify stereotypes, or produce confident but unsupported claims. Require learners to distinguish facts from assumptions and to identify the strongest rejected alternative. Do not use the exercise for medical, legal, employment, or other high-stakes decisions without qualified review. The lab should use a low-risk decision such as a team workflow or software tool and should not include confidential information.
