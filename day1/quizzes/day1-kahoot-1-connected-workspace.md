# Day 1 Kahoot 1: Connected Workspace and Data Retrieval

**Placement:** After Session 1 and Lab 1.1
**Scope:** Session 1 only

## Q1 (MCQ)

**Question:** What is the main benefit of connecting Workspace apps to Gemini?

A. It searches every Workspace app without scope
B. It retrieves relevant Workspace context
C. It confirms every retrieved claim
D. It bypasses file permissions

**Correct Answer:** B

**Rationale:** Connected Apps help Gemini find and summarize relevant content the user can access.

## Q2 (MCQ)

**Question:** Which prompt detail most improves a project-status request?

A. A generic request without a project name
B. A project, source, and output format
C. A conclusion without supporting evidence
D. A source name without a date range

**Correct Answer:** B

## Q3 (True/False)

**Question:** Gemini can always identify the newest email thread correctly.

A. True
B. False

**Correct Answer:** B

**Rationale:** Learners must check dates and cited sources because results can be outdated.

## Q4 (MCQ)

**Question:** What should you do before sharing a generated status report?

A. Remove the citations from the report
B. Open and check the original sources
C. Treat every inference as a confirmed fact
D. Share it without checking dates

**Correct Answer:** B

## Q5 (MCQ)

**Question:** In a connected prompt, what does `@Gmail` identify?
