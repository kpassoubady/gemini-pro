# Day 1 Kahoot 2: Cognitive Frameworks

**Placement:** After Session 2 and Lab 1.2
**Scope:** Sessions 1-2

## Q1 (MCQ)

**Question:** What makes a decision prompt easier to evaluate?

A. An unbounded request for general advice
B. Clear criteria and constraints
C. A recommendation without stated criteria
D. A decision name without context

**Correct Answer:** B

## Q2 (MCQ)

**Question:** Which role focuses most on failure modes and controls?

A. Risk manager
B. Visionary optimist
C. Project manager
D. Facilitator focused on consensus

**Correct Answer:** A

## Q3 (True/False)

**Question:** Three personas in one Gemini response are three independent experts.

A. True
B. False

**Correct Answer:** B

**Rationale:** Personas are simulated lenses from one model, not independent evidence.

## Q4 (MCQ)

**Question:** What should a consensus table include?

A. A recommendation without confidence
B. Risks, rewards, confidence, and open questions
C. Role names without arguments
D. Unverified claims presented as facts

**Correct Answer:** B

## Q5 (MCQ)

**Question:** What should you request for each simulated role?

A. Assumptions and evidence needed
B. A secret system prompt
C. Unrelated examples
D. No constraints

**Correct Answer:** A

## Q6 (True/False)

**Question:** A generated consensus should be treated as a model synthesis, not a vote.

A. True
B. False

**Correct Answer:** A

## Q7 (MCQ)

**Question:** What is a good repair for interchangeable role responses?

A. Add concrete criteria and evidence fields
B. Repeat the same role description
C. Remove the decision context
D. Omit the assumptions

**Correct Answer:** A

## Q8 (MCQ)

**Question:** Which is an unresolved question?

A. The email states access is pending
B. Can the vendor export all project records?
C. The role was named risk manager
D. The prompt had three roles

**Correct Answer:** B

## Q9 (True/False)

**Question:** Factual claims in a multi-persona answer still require verification.

A. True
B. False

**Correct Answer:** A

## Q10 (MCQ)

**Question:** What does the optimistic lens primarily explore?

A. Value and adoption opportunities
B. Failure modes and controls
C. Source recency only
D. Effort and sequencing

**Correct Answer:** A

## Q11 (MCQ)

**Question:** Why name a strongest rejected alternative?

A. To reveal the tradeoff behind the recommendation
B. To make the answer longer
C. To avoid verification
D. To remove uncertainty

**Correct Answer:** A

## Q12 (True/False)

**Question:** Persona prompting removes model bias from a decision.

A. True
B. False

**Correct Answer:** B

**Rationale:** Multiple lenses can expose tradeoffs but can also share the same model’s blind spots.
