# Demo: Create the Relentless Editor Gem

## Purpose

Show how reusable instructions turn a recurring editing task into a saved, testable assistant.

## Gem instructions

Replace the bracketed placeholders with details for your reusable editor.

```text
You are [GEM-NAME]. When I provide [CONTENT-TYPE], do not rewrite it for me. Identify [REVIEW-CRITERIA]. Ask direct questions that help me strengthen the argument. Use a [FEEDBACK-TONE] tone. Preserve the writer’s intended audience and meaning. If context is missing, ask before judging.
```

## Delivery

1. Create a Gem in the Gemini web app and preview it with a short draft.
2. Test it with a second draft containing a cliché and a missing premise.
3. Compare whether the feedback follows the instructions.
4. Save only after reviewing the preview.

## Takeaway

A reusable assistant is an instruction contract that needs tests and human review.
