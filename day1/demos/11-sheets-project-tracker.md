# Demo: Build and Verify a Sheets Tracker

## Purpose

Show how a natural-language request creates a project tracker, then verify the structure, dropdowns, and deadline formula.

## Prompt

Replace the bracketed placeholder with the project you want to track.

```text
Create a project tracking template for [PROJECT-TYPE] with columns for Task, Owner, Status, Deadline, and Days Until Deadline. Add a Status dropdown with Pending, In Progress, and Blocked. Add a formula that calculates the number of days from today to the Deadline. Use fictional sample tasks and show the formula range.
```

## Delivery

1. Start in a blank native Google Sheet.
2. Review the generated plan before applying it.
3. Test one value from each status and three known deadline cases.
4. Inspect the formula, date format, and range.

## Takeaway

Natural-language creation accelerates setup; verification establishes whether the tracker is usable.
