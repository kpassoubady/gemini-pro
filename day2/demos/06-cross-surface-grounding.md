# Demo: Compare Grounding Across Gemini Surfaces

## Purpose

Use one synchronized notebook in Gemini Notebook and Gemini Apps to show when an answer stays within notebook sources and when external tools may contribute information.

## Preparation

Create the policy-change notebook used in Demo 05. Keep only the policy and implementation guide selected. Confirm that the same notebook name and sources appear in Gemini Apps.

## Comparison question

```text
What does this notebook establish about the remote-access change, and has any later public guidance changed the recommended rollout approach? Separate notebook-supported statements from outside information. Cite notebook passages and provide links for any web evidence. If external tools are unavailable, say so.
```

## Delivery

1. Ask the question in standalone Gemini Notebook.
2. Confirm whether every answer claim maps to the selected source set.
3. Ask the same question with the synchronized notebook in Gemini Apps.
4. Mark claims as notebook evidence, outside evidence, or unsupported.
5. Explain why the Gemini Apps result may use web search or other tools.

## Offline fallback

- Standalone response: “The policy begins 15 October and requires enrollment by 10 October. The selected sources contain no later public guidance.”
- Gemini Apps response: “The notebook sets those dates. A recent public article recommends a phased rollout.”

The second response needs a separate link, date, and authority check. It must not present the public recommendation as part of the controlled notebook record.

## Takeaway

The notebook synchronizes across products, but answer grounding depends on the surface used for the conversation.
